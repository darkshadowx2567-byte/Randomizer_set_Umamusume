# ¿Sientes que Uma Musume no te genera un gran reto?
¡¡Pues intenta completar una partida con un set completamente aleatorio!

Uma Run Randomizer es lo que buscas, elige Una uma que tengas a tu disposición y te dira que tipo de cartas llevar, y en que encenario entrenar.

Eso no es todo, también podrás poner este factor aleatorio con las cartas. Mi página Support Card Deck Randomizer se encarga de ello, aquí pondrás las cartas que te han salido en la página anterior y te dará las cartas que usarás en el entrenamiento. Puedes filtrar por cada tipo, eliminando las que NO tengas a tu disposición. No vale descartar todas las R, ellas también merecen su oportunidad de jugar. Nuestra anfitriona Nakayama Festa te esperará para elegir tus cartas.

Aqui te dejo la página para que puedas probarla: https://darkshadowx2567-byte.github.io/Randomizer_set_Umamusume/index.html
